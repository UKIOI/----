# 霓虹乱斗（离线版）

这是从“版本1_本地版”独立复制出的离线版本，地图、障碍、道具、职业、聊天和战斗数值均与本地版相同。

## 启动方法

直接双击 `start_offline.bat`。启动成功后会自动打开：

```text
http://localhost:8083
```

游戏期间请保持黑色启动窗口开启。结束游戏时，在启动窗口按 `Ctrl+C`，然后输入 `Y` 并回车。

离线版服务器只监听 `127.0.0.1`，其他电脑和手机无法访问，也不会连接 Cloudflare 或生成公网地址。若想在同一台电脑测试多人，可以打开多个浏览器窗口并填写相同房间号。

进入房间后点击右上角“🤖 人机”，可以随时选择 0–11 个人机以及简单、普通或困难强度。人机会使用网格寻路绕过障碍，主动判断并拾取道具，预判来袭子弹；生命值低于 35% 时会优先拉开距离，再寻找血包。它们也会射击、参与计分和复活；职业模式中的人机会自动选择职业。重新应用设置会重建当前房间内的人机。

## 操作

- `WASD` 或方向键：移动
- 鼠标：瞄准
- 按住鼠标左键：射击
- 空格：使用圣骑士技能
- 右上角“聊天”：展开或收起聊天框
- `Esc`：退出当前房间

## 玩法模式

- 经典模式：场上道具数量等于玩家人数。
- 多道具模式：场上道具数量为玩家人数的三倍。
- 纯净模式：不生成道具。
- 职业模式：只生成血包，加入和死亡后需要选择职业。

离线版默认使用端口 `8083`，本地局域网版默认使用 `8081`，因此两个版本可以同时存在。
