# 霓虹乱斗

一个开箱即玩的浏览器多人 2D 混战小游戏。服务端负责移动、子弹、伤害、击杀和复活判定；客户端只发送操作并负责渲染。

## 本地启动

```powershell
cd C:\VSCodeProjects\多人乱斗\版本1
python -m pip install -r requirements.txt
python server.py
```

浏览器打开 `http://localhost:8080`。同一局的玩家填写相同房间号；局域网玩家可访问 `http://你的局域网IP:8080`。

## 互联网联机

### 使用官方开源 FRP（当前主要方案）

互联网版启动器会自动查找桌面、下载目录或项目 `frp` 子目录中的官方 `frpc.exe` 与同目录的 `frpc.toml`，校验配置后依次启动游戏服务器和 FRP 客户端。当前配置应将 `127.0.0.1:8080` 映射到云服务器的公网端口，例如 `60052`。

双击 `start_internet.bat`。成功后窗口会直接显示完整分享网址，例如 `http://47.99.181.198:60052`；把该网址和房间号发给朋友。关闭该窗口会同时停止游戏服务器和 FRP 客户端。

开源 FRP 不提供公共节点：云服务器必须提前运行版本兼容的 `frps`，并在云平台安全组及服务器系统防火墙放行 FRP 控制端口（配置中的 `serverPort`）和游戏公网端口（配置中的 `remotePort`）。建议为 `frps` 和 `frpc` 配置相同的 `auth.token`。

本游戏的浏览器通信使用 HTTP + WebSocket（TCP），不需要 UDP 映射。若修改游戏端口，可在终端运行 `.\start_internet.bat -Port 8082`，同时把 `frpc.toml` 的 `localPort` 改为 `8082`。FRP 放在其他位置时可传入 `.\start_internet.bat -FrpDirectory "D:\path\to\frp"`。

Cloudflare 方案仍保留为 `start_cloudflare.bat`，可在自建 FRP 服务端不可用时临时使用。

遇到无法连接时可双击 `check_frp.bat`。自检工具会依次检查 FRP 文件、配置语法、token 是否存在、本地游戏、云服务器控制端口及公网游戏端口，不会显示 token 内容。

### 长期部署（固定网址）

将本目录推送到 GitHub，然后在 Render、Railway、Fly.io 等支持 Docker 与 WebSocket 的平台创建服务，平台会读取 `Dockerfile`。部署完成后分享 HTTPS 地址和房间号即可。服务器使用平台提供的 `PORT`，无需额外配置。

若在自有云主机运行，请在防火墙开放 8080 端口，或用 Caddy/Nginx 将 HTTPS/WSS 反向代理到 `127.0.0.1:8080`。

## 操作

- `WASD` 或方向键：移动
- 鼠标：瞄准
- 按住鼠标左键：射击
- 右上角“聊天”：展开或收起房间聊天；输入时游戏移动会自动停止
- `Esc`：退出当前房间

手机和平板会自动显示双轮盘：左轮盘控制移动，右轮盘控制瞄准方向并持续射击。手机端和电脑端使用相同房间号即可互相联机。

手机端建议横屏游玩。页面会使用手机浏览器的实际可视区域自动调整画布、相机、HUD 和双轮盘，并避开刘海与底部安全区；竖屏时会显示横屏提示。

手机端战场使用约 72% 的视图缩放以展示更大范围，并限制高分屏渲染倍率、跳过屏幕外物体和降低昂贵光影效果；玩家与随从位置会在网络帧之间平滑显示。

互联网状态同步使用 30 次/秒物理运算与 25 次/秒压缩网络帧。116 个静态地形块只在加入时发送一次，之后仅同步被摧毁部分；坐标会压缩精度并向玩家并行发送。客户端会即时预测自己的移动和子弹的帧间位置，并由服务器确认停止坐标，减少角色前后抽搐。输入中断超过 0.75 秒时服务器会自动刹车，避免断网后继续移动或射击。HUD 同时显示当前往返延迟。

普通玩家及职业子弹的存在时间为 2.5 秒，普通子弹最大射程约 1900 像素，足以覆盖地图最长方向；随从子弹的射程也已延长。子弹命中玩家、随从或不可反弹的障碍物时仍会正常消失。

每发命中造成 25 点伤害；击败对手加 1 分，2.5 秒后复活。每个房间最多 12 人，房内玩家会优先获得互不重复的高区分度颜色。

地图中的道具数量始终等于房间在线人数，普通增益持续 10 秒。道具包括：伤害提升、高速射击、三重散射、半血反射激光、普通伤害减半且激光伤害降低 75% 的护盾、残影加速、高能光束、恢复 25 点生命的血包、反弹弹药，以及低射速、70 点范围伤害的攻城大炮。大炮可炸毁爆炸范围内的地形块，地形在 5 秒后恢复。

战斗随从道具没有时间限制并可无限叠加。每个随从拥有玩家三分之一的生命值，环绕主人飞行，并自动向 650 距离内最近的敌人发射 10 点伤害子弹；随从被子弹、激光或爆炸耗尽生命后消失。

## 玩法模式

- 经典模式：场上道具数量等于在线人数。
- 多道具模式：场上道具数量为在线人数的三倍。
- 纯净模式：不生成任何道具。
- 职业模式：只生成血包；加入房间和每次死亡后都要重新选择职业，选定后重新出生，击杀分数保留。

职业模式中，坦克拥有 300 点生命；法师发射 37.5 点伤害、半径 78 的范围爆炸弹；狙击手发射 75 点伤害（三倍普通伤害）的高速子弹；死灵法师或其随从每次击杀玩家都会永久生成一只拥有主人三分之一生命、可自主追击并攻击敌人的永久随从。

武器大师每隔 20 秒会随机获得三重子弹、反射激光、高能光束、反弹弹药或攻城大炮之一，武器持续 10 秒。圣骑士按空格发动圣盾，无敌并获得 45% 移速提升 5 秒、冷却 20 秒；手机端使用右侧轮盘上方的“圣盾”按钮。
